# Costa&Costa — Alimentação Forte

Aplicativo comercial de planejamento alimentar e hábitos saudáveis, com cardápio semanal, receitas, lista de compras e acompanhamento opcional.

## Stack

- React, TypeScript e Vite
- Supabase para autenticação, banco PostgreSQL e armazenamento
- PWA responsivo

## Desenvolvimento

As funcionalidades serão desenvolvidas em branches isoladas, com migrações versionadas, testes e validação antes de integrar à `main`.

O conteúdo nutricional é educativo e não substitui avaliação profissional. Não inserir segredos, credenciais ou chaves de serviço no repositório.
